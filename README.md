# ASTANA GUIDE — Тур-гид по Астане

## О проекте

**ASTANA GUIDE** — это веб-приложение, которое помогает пользователям знакомиться с интересными местами, архитектурой и достопримечательностями столицы Казахстана.

На сайте можно просматривать информацию о достопримечательностях, открывать отдельные страницы с подробным описанием и узнавать полезную информацию о посещении.

Проект разработан с использованием Node.js, Express, EJS и MongoDB.

## Основные возможности

- Просмотр списка достопримечательностей Астаны.
- Просмотр подробной информации о каждом месте.
- Добавление новых достопримечательностей через панель администратора.
- Авторизация администратора по логину и паролю.
- Защита страницы добавления достопримечательностей.
- Сохранение данных в MongoDB.
- Выход из аккаунта администратора.
- Отображение страниц ошибок и страницы 404.

## Используемые технологии

- **HTML** — структура страниц.
- **CSS** — оформление и дизайн сайта.
- **JavaScript** — логика приложения.
- **Node.js** — серверная среда.
- **Express.js** — серверный фреймворк.
- **EJS** — шаблонизатор страниц.
- **MongoDB** — база данных.
- **bcrypt** — хеширование и проверка пароля.
- **express-session** — управление сессиями администратора.

## Установка и запуск

1. Склонировать репозиторий:

```bash
git clone ссылка-на-репозиторий
```

2. Перейти в папку проекта:

```bash
cd project
```

3. Установить зависимости:

```bash
npm install
```

4. Создать файл `.env` в корне проекта и добавить настройки MongoDB и администратора.

5. Запустить сервер:

```bash
node server.js
```

6. Открыть сайт в браузере:

```text
http://localhost:3000
```

## Авторизация администратора

Для доступа к служебным функциям предусмотрена отдельная страница входа.

Администратор может:
- Войти в систему по логину и паролю.
- Добавлять новые достопримечательности.
- Сохранять информацию в базе данных.
- Завершать сеанс с помощью кнопки «Выйти».

Пароль администратора хранится в виде хеша с использованием bcrypt. Доступ к странице добавления защищён авторизацией.

## База данных

Для хранения информации используется MongoDB.

Коллекция `places` содержит данные о достопримечательностях:
- `id` — идентификатор.
- `title` — название.
- `description` — описание.
- `category` — категория.
- `time` — время посещения.
- `image` — изображение.

## Цель проекта

Цель проекта — создать удобный веб-сайт, который поможет пользователям открыть для себя Астану, узнать больше о её достопримечательностях и выбрать интересные места для посещения.
